# ลอยกระทงออนไลน์ (เวอร์ชัน Netlify)

```
public/index.html                หน้าเว็บทั้งหมด
netlify/functions/krathongs.mjs  API เก็บกระทงของทุกคน (Netlify Blobs)
netlify.toml / package.json      ตั้งค่า Netlify
```

## วิธีขึ้น Netlify

> ห้ามใช้วิธีลากโฟลเดอร์ไปวาง (drag & drop) เพราะวิธีนั้นจะไม่ build ส่วน API ให้ แม่น้ำจะไม่แชร์กัน

**ทางที่ 1: ผ่าน GitHub (แนะนำ)**
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo ใหม่
2. ใน Netlify กด Add new site → Import an existing project → เลือก repo นั้น
3. ช่องการตั้งค่า build ไม่ต้องแก้อะไร ระบบจะอ่านจาก netlify.toml เอง แล้วกด Deploy

**ทางที่ 2: ผ่าน Netlify CLI**
```
npm install
npx netlify-cli login
npx netlify-cli deploy --prod
```

## ตั้งรหัสผู้ดูแล (ไว้ลบกระทงที่ไม่เหมาะสม)
1. ไปที่ Site configuration → Environment variables → เพิ่ม `ADMIN_KEY` ใส่รหัสยาวๆ ที่เดายาก
2. Redeploy เว็บ 1 ครั้ง
3. เปิด `https://ชื่อเว็บ.netlify.app/?admin=รหัสของคุณ` แค่ครั้งเดียว เบราว์เซอร์นั้นจะจำไว้
   จากนั้นแตะกระทงใบไหนก็จะมีปุ่ม "เอาออกจากแม่น้ำ" ให้กด

## รูปบนกระทง
- ผู้ใช้เลือกรูป แล้วลากหรือซูมเพื่อครอปเป็นวงกลมได้ในหน้าเว็บ
- รูปจะถูกย่อในเครื่องผู้ใช้เหลือ 192×192 JPEG (ราว 10–30 KB) ก่อนส่งขึ้นเซิร์ฟเวอร์
- เซิร์ฟเวอร์รับเฉพาะ JPEG ไม่เกิน 70 KB เก็บไว้ใน Netlify Blobs และส่งให้ผู้ชมแบบ cache ยาว

## กันสแปม
- คนหนึ่งลอยได้ 1 ใบทุก 20 วินาที (นับตาม IP)
- ชื่อยาวได้ไม่เกิน 30 ตัวอักษร คำอธิษฐานไม่เกิน 160 ตัวอักษร และห้ามใส่ลิงก์
- ถ้าอยากบล็อกคำไหนเพิ่ม ให้แก้ `BANNED` ใน netlify/functions/krathongs.mjs
- ปุ่ม "แจ้งไม่เหมาะสม": ถ้ามีคนแจ้งครบ 3 IP กระทงใบนั้นจะถูกซ่อนเองทันที (ข้อมูลไม่ได้ถูกลบ ผู้ดูแลลบเองได้)
- หน้าเว็บแสดงกระทงล่าสุด 150 ใบ และดึงข้อมูลใหม่ทุก 15 วินาที

## ศึกกระทง (ออนไลน์)
- กระทงที่ลอยจริงคือตัวละครของเจ้าของ ตอนลอยเซิร์ฟเวอร์ออก "กุญแจ" ให้เบราว์เซอร์นั้น (เก็บใน localStorage) และเก็บไว้แค่ค่า hash ของกุญแจ
- ค่าพลัง เหรียญ สกิล และสถิติ เก็บใน Netlify Blobs ที่ `prog/<id>` ส่วนประวัติการถูกท้าเก็บที่ `ch/<id>/<เวลา>`
- **กระทงจริงในแม่น้ำไม่ถูกลบหรือล่ม** ล่มเฉพาะในศึก
- **เหรียญ:** เริ่มต้น 60
  - ด่านฝึก: ชนะได้ 20 + ด่าน×10 และได้เพิ่ม kill ละ 4
  - ท้าดวล: ชนะได้ 40 แพ้ได้ 8
  - ฝั่งที่ถูกท้าแล้วป้องกันได้: +15 เหรียญ +1 kill
- **อัปเกรด:** แต่ละค่าพลังอัปได้ถึงเลเวล 20 ราคาเลเวลถัดไป = 25 + เลเวลปัจจุบัน×15
- **ล้างค่าพลัง:** รีเซ็ตทุกค่ากลับเป็นเลเวล 0 แล้วคืนเหรียญที่ใช้อัป ครั้งแรกคืนเต็ม ครั้งต่อไปคืน 80%
- **สกิล:** แต่ละกระทงมีสกิลประจำตัว 1 สกิล และสกิลจากเซียมซี 1 สกิล เสี่ยงเซียมซีใหม่ 40 เหรียญ (ครั้งแรกฟรี)
- **ข้อความสด:** ทุกศึกท้าดวล และการผ่านด่านฝึกตั้งแต่ด่าน 3 ขึ้นไป เก็บไว้ที่ `feed/` (เก็บ 300 รายการล่าสุด) ทุกคนที่เปิดเว็บจะเห็นแถบข้อความเด้งขึ้นภายใน 15 วินาที
- **บอร์ด:** ปุ่มบอร์ดมี 3 แท็บ คือ กระทง, ทำเนียบนักชน และศึกล่าสุด
- **ยกระดับดาว ★ (สูงสุด ★5):** อัปทุกค่าให้ตันก่อน ราคา 2,500 × ดาวถัดไป ได้ค่าพลังทุกตัว +8% และเพดานเลเวลเพิ่ม 5
- **คลาส (ปลดล็อกเมื่อกระทงถึง Lv.20 — ขยักแรก):**
  - นักรบสายน้ำ, ผู้พิทักษ์บัวทอง, จอมเวทจันทรา, นักซิ่งสายรุ้ง
  - แต่ละคลาสมีโบนัสค่าพลังและสกิลคลาส 1 สกิล (เป็นปุ่มที่ 3)
  - เลือกครั้งแรกฟรี เปลี่ยนไปมาได้ตลอด ครั้งละ 200 เหรียญ
- **ด่านบอส:** ทุก 5 ด่าน เจอบอสตัวใหญ่สวมมงกุฎ ชนะได้เหรียญ x2
- **กันฟาร์ม:**
  - เซิร์ฟเวอร์จำด่านฝึกเอง ไม่เชื่อเลขที่เบราว์เซอร์ส่งมา
  - ท้าคนเดิมซ้ำภายใน 15 นาทีได้แค่ 2–4 เหรียญ
  - ชนะดวลได้ 10–70 เหรียญตามความเก่งของอีกฝ่าย
  - ได้เกิน 2,500 เหรียญในชั่วโมงเดียว เหรียญที่ได้หลังจากนั้นลดเหลือ 20%
  - ฝั่งป้องกันได้ HP +15% และคอมสู้ดุขึ้น
- **ข้อจำกัด:** ศึกคำนวณในเบราว์เซอร์ เซิร์ฟเวอร์จึงทำได้แค่จำกัดผล (เหรียญต่อศึกมีเพดาน, kill ไม่เกินจำนวนศัตรู, บันทึกได้ 1 ศึกทุก 12 วินาที) คนที่ตั้งใจโกงยังปลอมผลได้ ถ้าจะจริงจังต้องย้ายการคำนวณศึกไปไว้บนเซิร์ฟเวอร์

## หีบสมบัติ & เครื่องราง (กาชา)
- ตั๋ว: ผ่านชั้น 10 = 1 (ครั้งแรก 3), ชั้น 15 = 1, ชั้น 20 = 2 (ครั้งแรก 5) หรือซื้อเปิด 3,000 เหรียญ/ครั้ง
- โอกาส UR 3% · SSR 12% · SR 30% · R 55% · การันตี UR ทุก 40 ครั้ง · ได้ซ้ำ = เลเวลขึ้น (สูงสุด 5, +25%/เลเวล) เต็มแล้วคืน 500 เหรียญ
- ใส่ได้ 2 ช่อง/กระทง แสดงเป็นเครื่องรางห้อยข้างกระทง (ทั้งในแม่น้ำและในศึก) UR มีออร่า VFX
- R: เกล็ดปลาเงิน (HP), ขนกาเงา (SPD) · SR: เขี้ยวอสรพิษ (ATK), กะลาหินดำ (DEF) · SSR: ตากะโหลกสาป (คริ), หยดน้ำบาดาล (ฟื้น HP/SP) · UR: มงกุฎราชาปีศาจ (ไฟนรกระเบิดเมื่อชน), ดวงใจบัวทอง (ทุกค่า + ฟื้นคืนชีพ 1 ครั้ง)
- ไอคอน: `img/relic/*.png` (tools/relic_art.py)

### เซ็ตเครื่องราง (ใส่ครบ 2 ชิ้น = สกิลเซ็ต ปุ่มเพิ่ม)
- เซ็ตพญานาค: เกล็ดพญานาค (SSR) + แก้วมณีนาคา (UR) → นาคาพิโรธ (คลื่นพญานาคใส่ศัตรูทุกตัว)
- เซ็ตจันทรา: ปิ่นจันทรา (SR) + โคมกระต่ายจันทร์ (SSR) → แสงจันทร์คุ้มภัย (ฟื้น 25% + เกราะ + ล้างพิษ/สาป/ช้า)
- เซ็ตอสูรเพลิง: แหวนอสูร (SR) + ดาบเพลิงอสูร (SSR) → ฟันเพลิงอสูร (ฟันเป็นแนว 55)
- เซ็ตครุฑวายุ: ขนครุฑ (SSR) + กงจักรวายุ (UR) → พายุครุฑ (ผลักทั้งสนาม + เร็วขึ้น)
- ใส่ครบเซ็ตแล้วกระทงมีวงแสงสีเซ็ตเชื่อมเครื่องราง · VFX: nagawave, moonlight, fireslash, garudastorm

- โบนัสทีม: คลาสไม่ซ้ำ 3 แบบ (ATK/DEF +10%), ครบเซ็ต 2 ลำ (HP +10%), กระทงแบบเดียวกันทั้งทีม (SP +20%)
- เจ้าของกระทงที่ถูกชวนได้ 20% ของเหรียญรอบนั้น (สูงสุด 1,500/ชั่วโมง) และขึ้นในกล่อง “ใครมาท้าฉัน”

## กระทงพิเศษ: กระทงคงคาสวรรค์
- ปลดล็อกหลังพิชิตชั้น 20 (หลังฉากพรพระแม่คงคาจะมีการ์ด “ปลดล็อกกระทงพิเศษ”) · เซิร์ฟเวอร์ตรวจ token ของกระทงที่ผ่านชั้น 20 ก่อนให้ลอยแบบนี้
- ค่าพลัง HP 140 / ATK 15 / DEF 14 / SPD 1.05 · ติดตัว: ฟื้น HP 2/วิ + SP +20% · สกิล “คงคาประทานพร” (คลื่นศักดิ์สิทธิ์ 30 ทุกตัว + ฟื้นทีม 20% + ล้างสถานะ)
- ขยับได้: ประกายทองวิ่งบนกลีบ/พญานาค, หยดน้ำในรูปเรืองแสงเป็นจังหวะ, หยดน้ำศักดิ์สิทธิ์ลอยวน, ละอองทองลอยจากเทียน

## เพลง
- สร้างด้วย PixelLab (/music) ผ่าน `tools/music_gen.py` — ไม่ได้โหลดหรือก๊อปเพลงจากที่อื่น
- main (แม่น้ำ), magic (ฉากลับ/ฉากจบ), battle (ศึกทั่วไป, orchestral rock เร้าใจ), boss (เจอบอส, คอรัส + ออร์แกน) — แต่ละเพลงมี 2 เวอร์ชันสุ่ม
- เปิดเพลงเป็นค่าเริ่มต้น เริ่มเล่นเมื่อแตะ/คลิกครั้งแรก (ข้อจำกัดเบราว์เซอร์) ปิดแล้วจำค่าไว้ที่ `lk.sound`

## สกินคลาส + ประกาศอัปเดต
- สกินกระทงประจำคลาส 4 แบบ (`img/kr/skin_<class>.png`) ใส่/ถอดได้ในหน้าอัปเกรดเมื่อมีคลาสแล้ว (`?action=skin {on}`) เปลี่ยนแค่หน้าตา ค่าพลังยังเป็นของแบบกระทงเดิม คนอื่นเห็นในแม่น้ำด้วย
- ปุ่ม 📢 ประกาศ: รายการอัปเดตอยู่ใน `UPDATES` (ใหม่สุดอยู่บน) มีจุดแดงเมื่อยังไม่อ่าน และเด้งขึ้นเองครั้งเดียวสำหรับคนที่เคยเข้าเว็บแล้ว — เพิ่มอัปเดตใหม่ให้ใส่รายการบนสุดพร้อม id ใหม่
