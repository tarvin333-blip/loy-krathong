# ลอยกระทงออนไลน์ (เวอร์ชัน Netlify)

```
public/index.html                หน้าเว็บทั้งหมด
netlify/functions/krathongs.mjs  API เก็บกระทงของทุกคน (Netlify Blobs)
netlify.toml / package.json      ตั้งค่า Netlify
```

## วิธีขึ้น Netlify

> ห้ามใช้วิธีลากโฟลเดอร์ไปวาง (drag & drop) เพราะวิธีนั้นจะไม่ build ส่วน API ให้ แม่น้ำจะไม่แชร์กัน

**ทางที่ 1: ผ่าน GitHub (แนะนำ)**
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo ใหม่
2. ใน Netlify กด Add new site → Import an existing project → เลือก repo นั้น
3. ช่องการตั้งค่า build ไม่ต้องแก้อะไร ระบบจะอ่านจาก netlify.toml เอง แล้วกด Deploy

**ทางที่ 2: ผ่าน Netlify CLI**
```
npm install
npx netlify-cli login
npx netlify-cli deploy --prod
```

## ตั้งรหัสผู้ดูแล (ไว้ลบกระทงที่ไม่เหมาะสม)
1. ไปที่ Site configuration → Environment variables → เพิ่ม `ADMIN_KEY` ใส่รหัสยาวๆ ที่เดายาก
2. Redeploy เว็บ 1 ครั้ง
3. เปิด `https://ชื่อเว็บ.netlify.app/?admin=รหัสของคุณ` แค่ครั้งเดียว เบราว์เซอร์นั้นจะจำไว้
   จากนั้นแตะกระทงใบไหนก็จะมีปุ่ม "เอาออกจากแม่น้ำ" ให้กด

## รูปบนกระทง
- ผู้ใช้เลือกรูป แล้วลากหรือซูมเพื่อครอปเป็นวงกลมได้ในหน้าเว็บ
- รูปจะถูกย่อในเครื่องผู้ใช้เหลือ 192×192 JPEG (ราว 10–30 KB) ก่อนส่งขึ้นเซิร์ฟเวอร์
- เซิร์ฟเวอร์รับเฉพาะ JPEG ไม่เกิน 70 KB เก็บไว้ใน Netlify Blobs และส่งให้ผู้ชมแบบ cache ยาว

## กันสแปม
- คนหนึ่งลอยได้ 1 ใบทุก 20 วินาที (นับตาม IP)
- ชื่อยาวได้ไม่เกิน 30 ตัวอักษร คำอธิษฐานไม่เกิน 160 ตัวอักษร และห้ามใส่ลิงก์
- ถ้าอยากบล็อกคำไหนเพิ่ม ให้แก้ `BANNED` ใน netlify/functions/krathongs.mjs
- ปุ่ม "แจ้งไม่เหมาะสม": ถ้ามีคนแจ้งครบ 3 IP กระทงใบนั้นจะถูกซ่อนเองทันที (ข้อมูลไม่ได้ถูกลบ ผู้ดูแลลบเองได้)
- หน้าเว็บแสดงกระทงล่าสุด 150 ใบ และดึงข้อมูลใหม่ทุก 15 วินาที

## เพลง
- `public/audio/main_1.mp3`, `main_2.mp3` (ฉากหลัก) และ `magic_1.mp3`, `magic_2.mp3` (ฉากลับ) แต่งด้วย PixelLab ผ่าน `tools/music_gen.py` คำสั่งที่ใช้แต่งเก็บอยู่ใน `tools/music.json`
- หน้าเว็บสุ่มเลือก 1 เวอร์ชันต่อการเปิดเว็บแต่ละครั้ง และเล่นวนแบบค่อยๆ ผสมตอนจบเข้ากับตอนต้น
- `tools/compose.py` คือเพลงแบบสังเคราะห์เสียงชุดเดิม เก็บไว้เป็นตัวสำรอง

## ศึกกระทง (ออนไลน์)
- กระทงที่ลอยจริงคือตัวละครของเจ้าของ ตอนลอยเซิร์ฟเวอร์ออก "กุญแจ" ให้เบราว์เซอร์นั้น (เก็บใน localStorage) และเก็บไว้แค่ค่า hash ของกุญแจ
- ค่าพลัง เหรียญ สกิล และสถิติ เก็บใน Netlify Blobs ที่ `prog/<id>` ส่วนประวัติการถูกท้าเก็บที่ `ch/<id>/<เวลา>`
- **กระทงจริงในแม่น้ำไม่ถูกลบหรือล่ม** ล่มเฉพาะในศึก
- **เหรียญ:** เริ่มต้น 60
  - ด่านฝึก: ชนะได้ 20 + ด่าน×10 และได้เพิ่ม kill ละ 4
  - ท้าดวล: ชนะได้ 40 แพ้ได้ 8
  - ฝั่งที่ถูกท้าแล้วป้องกันได้: +15 เหรียญ +1 kill
- **อัปเกรด:** แต่ละค่าพลังอัปได้ถึงเลเวล 20 ราคาเลเวลถัดไป = 25 + เลเวลปัจจุบัน×15
- **ล้างค่าพลัง:** รีเซ็ตทุกค่ากลับเป็นเลเวล 0 แล้วคืนเหรียญที่ใช้อัป ครั้งแรกคืนเต็ม ครั้งต่อไปคืน 80%
- **สกิล:** แต่ละกระทงมีสกิลประจำตัว 1 สกิล และสกิลจากเซียมซี 1 สกิล เสี่ยงเซียมซีใหม่ 40 เหรียญ (ครั้งแรกฟรี)
- **ข้อความสด:** ทุกศึกท้าดวล และการผ่านด่านฝึกตั้งแต่ด่าน 3 ขึ้นไป เก็บไว้ที่ `feed/` (เก็บ 300 รายการล่าสุด) ทุกคนที่เปิดเว็บจะเห็นแถบข้อความเด้งขึ้นภายใน 15 วินาที
- **บอร์ด:** ปุ่มบอร์ดมี 3 แท็บ คือ กระทง, ทำเนียบนักชน และศึกล่าสุด
- **ข้อจำกัด:** ศึกคำนวณในเบราว์เซอร์ เซิร์ฟเวอร์จึงทำได้แค่จำกัดผล (เหรียญต่อศึกมีเพดาน, kill ไม่เกินจำนวนศัตรู, บันทึกได้ 1 ศึกทุก 12 วินาที) คนที่ตั้งใจโกงยังปลอมผลได้ ถ้าจะจริงจังต้องย้ายการคำนวณศึกไปไว้บนเซิร์ฟเวอร์

## ภาพปกตอนแชร์ลิงก์ (Facebook, LINE, X)
- ภาพปกอยู่ที่ `public/img/og-cover.jpg` ขนาด 1200×630
- ป้ายกำกับ og:* อยู่ใน `<head>` ของ `public/index.html`
- Facebook ต้องการลิงก์ภาพแบบเต็ม ตอนนี้ใช้ https://remarkable-fenglisu-d58300.netlify.app ถ้าเปลี่ยนโดเมน ให้แก้ที่อยู่ในป้าย og:url, og:image และ twitter:image
- ถ่ายภาพปกใหม่: รัน `node tools/og/ogserver.mjs` แล้วตามด้วย `node tools/og/shoot.js` (ต้องมี Playwright) ภาพจะออกมาเป็น og_raw.png ย่อเหลือ 1200×630 แล้ววางทับไฟล์เดิม
- กระทงในภาพปกเป็นชื่อสมมติทั้งหมด
- ถ้า Facebook ยังโชว์ภาพเก่า ให้เปิด https://developers.facebook.com/tools/debug/ วางลิงก์ แล้วกด "Scrape Again"

## เอฟเฟกต์สกิล (VFX)
- ภาพเอฟเฟกต์อยู่ที่ `public/img/vfx/*.png` ขนาดและจำนวนเฟรมอยู่ใน `vfx.json`
- 14 แบบนำมาจากคลัง VFX ในเกม bara-duel ของเจ้าของเว็บ
- 4 แบบ (lotus, fish, rainbow, meteor) แต่งใหม่ด้วย PixelLab ผ่าน `tools/vfx_gen.py`
- รวบรวมไฟล์ใหม่ด้วย `python3 tools/vfx_pack.py <โฟลเดอร์คลัง VFX ของเกม>`
